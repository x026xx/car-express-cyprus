# CAR EXPRESS CYPRUS

Static premium automotive website for GitHub Pages.

## Files
- `index.html` — page structure/content
- `style.css` — design and responsive layout
- `script.js` — vehicle database, filters, modal and WhatsApp

## Before publishing
Open `script.js` and change:
1. `WHATSAPP_NUMBER`
2. Demo vehicle information in `cars`
3. Vehicle image URLs
4. Contact details in `index.html`

This is an original implementation inspired by the general structure of premium automotive dealer websites. It does not use the original site's branding, code, or assets.
